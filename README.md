# MyCalc — Kalkulator Ilmiah

Aplikasi kalkulator berbasis HTML, CSS, dan JavaScript tanpa dependensi eksternal.

## Menjalankan secara lokal
1. Buka `index.html` di browser modern.
2. Gunakan tombol kalkulator atau ketik ekspresi di kolom ekspresi.
3. Tekan Enter atau tombol `=` untuk menghitung.

## Fitur
- Operasi aritmetika, kurung, pangkat, modulus, persen, faktorial
- Fungsi trigonometri (DEG/RAD), invers, log, ln, akar, abs
- Konstanta pi dan e, perkalian implisit
- Riwayat perhitungan, salin hasil, tema

## Publikasi ke GitHub Pages
1. Buat repositori publik bernama `MyCalc` di GitHub.
2. Unggah `index.html` ke root repositori (file ini wajib bernama `index.html`).
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**, branch `main`, folder `/(root)`, lalu **Save**.
5. Setelah deploy selesai, situs akan tersedia di `https://USERNAME.github.io/MyCalc/`.
